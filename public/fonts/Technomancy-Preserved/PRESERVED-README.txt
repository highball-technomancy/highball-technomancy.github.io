TECHNOMANCY v4

The 13 letters in HIGHBALL TECHNOMANCY are traced from the original artwork with subpixel brightness contours and light smoothing. Their shapes are no longer substituted with geometric redesigns. Comparison uses matching cap heights and original letter positions to separate shape from typesetting. Generated repeated letters may vary slightly; this font uses one consistent glyph per letter.

Other letters and punctuation remain inferred extensions from v3, not letters present in the reference. Lowercase maps to uppercase. Install the TTF as Technomancy; replace the previous Technomancy version and restart the application if it caches fonts.

The source image limits exactness at very large sizes. WOFF2 included for web use.
